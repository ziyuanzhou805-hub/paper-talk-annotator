# 本地排版与 PDF 批注

使用有 `pdfplumber`、`pypdf`、`reportlab`、`python-docx` 的 Python。Codex 桌面可先用工作区依赖工具定位自带环境。批注字体用可嵌入的 TrueType 或 TTC，Windows 中文可用 `C:/Windows/Fonts/simsun.ttc`。脚本只用本地文件。

## 1 读页和获取锚点

```text
python scripts/inspect_pdf.py paper.pdf --pages 1-6 --column all
```

默认读全部页，`--column F` 输出整宽文本，`--column LR` 输出左右栏。左右分界默认页面宽度的 0.5，可用 `--split` 修改。整宽文本适合单栏、标题、摘要和横跨两栏的表。输出带 PDF 页、行号、页上距与左右边界。行号用于定位，不等于阅读顺序。若有错码或图表为图片，渲染原页判读，必要时本地 OCR；图中数字和行标题仍须看图核实。查看源 PDF 的已有批注数量、页框和旋转状态。

## 2 讲稿源文件

UTF-8。`# ` 是标题，`@ ` 是演讲前说明，`## ` 是主题，`### ` 是小标题，`> ` 是演讲者翻页提示并含 `[01]` 等编号。正文用普通段落，`===` 可让下一主题另起一页。稿末用 `* ` 添加来源，可在行末追加 ` | https://…` 作为可点链接。编号按实际讲述节点分配，允许同一编号出现在相关的多个 PDF 页。例：

```text
# 论文题目组会讲稿
@ 约十二分钟。蓝色页码提示供演讲者查看。
## 01 问题与比较对象
> PDF 第 2 页 · 图 1 · [01]
请看图 1 左边的流程。这一组是……
```

```text
python scripts/build_talk.py talk.txt talk.docx
```

逐页渲染核查。可用当前 Codex 文档渲染器；无 LibreOffice 的 Windows 可用本地 WPS 或 Word 只读导出预览再用 Poppler 渲染。长讲稿按可自然停顿的位置分页，发现孤行或溢出再调整。

## 3 批注计划与写入

UTF-8，每行 `PDF物理页|类型|锚点|可选批注文字`。在计划开头可复制检查脚本输出的 `# source-sha256=...` 绑定版本。`gray/red/blue` 为原生墨迹下划线，`yellow` 为原生高亮，`box` 为参数框，`note` 为可见旁注，`comment` 为橙色可点开批注。正文锚点由 `行号:原文片段` 构成，同行文字需唯一，多行用 `;` 分隔。坐标为左上原点、PDF 点单位，形式为 `@x0,top,x1,bottom`，适合核实过的图表框或扫描页区域。`yellow` 用原文字符边界，图表区域优先 `box` 或 `comment`。

```text
2|red|L13:研究问题;L14:主要目标|[01] 两句话交代为什么研究这个问题。
2|note|left@L13|[01]/研究问题
2|comment|right@248.5|[02] 先看横轴的比较组，再核对误差线含义。
2|box|@162,220,178,233|[02] 图1中用于比较的参数。
```

`note/comment` 锚点为 `left@行号`、`right@行号` 或 `left@距页面顶端的点数`。可见短旁注用 `/` 手动换行。若边距窄，缩短旁注、调小 `--note-width`，或用带编号的 `comment`；核对标记不盖正文。双栏锚点在两次命令中使用相同的 `--split`。只有实际发现某种字体的行内拉丁字母提取框下移时才考虑 `--align-inline-latin`，并重新核对位置。

```text
python scripts/annotate_pdf.py paper.pdf plan.txt annotated.pdf --font FONT --talk talk.txt
```

脚本验证可读批注、页数、既有批注和讲稿编号。翻页提示用 `PDF 第 2 页` 或 `PDF 第 2–4 页` 格式写物理页，脚本可额外核对编号的落页。期刊印刷页码可另写在前置说明。相同的输入、输出路径会被拒绝。脚本坐标支持无旋转、左下原点为零且裁切框等于媒体框的页面。遇非标准页框或旋转页，用支持对应坐标变换的 PDF 工具创建可编辑批注，再逐页校验几何和原始内容。不要为定位便利重新排版源文。渲染时可对原稿和批注稿使用同样的 `pdftoppm -hide-annotations` 参数比较页面底图，再开启批注检查可见层。用于验收的文件是讲稿和带原生批注的 PDF，文本计划及预览属于工作材料。

## 4 添加同页可见的详细解读

先完成正文锚定，再用 UTF-8 文本写页边计划，每行 `PDF物理页|带编号的小标题|原文锚点描述|具体解读`。在标题保留讲稿 `[NN]`；同一编号可以在不同页重复。锚点写读者能找到的段落、图表、行名或原词。每条解读直接显示在 PDF 右边，内容需要在不开弹窗的情况下完整成立。示例格式：

```text
3|[04] 为什么选择 K=2|图 2 左图 · 中文语料|横轴是候选主题数 K，纵轴是主题一致性。先在 K=1–9 的候选范围内找峰值，再看作者是否使用峰值对应的 K。解释时写出图中的实际得分，并交代比较只在同组语料内成立。
```

```text
python scripts/add_margin_notes.py annotated.pdf margin-plan.txt annotated-with-margin.pdf --font FONT --bold-font BOLD_FONT --talk talk.txt
```

Windows 中文可用 `C:/Windows/Fonts/msyh.ttc` 和 `C:/Windows/Fonts/msyhbd.ttc`；没有单独粗体时省略 `--bold-font`。默认扩宽 240 pt，正文用 10.5 pt；空间不足先用 `--rail-width 260` 或调整重复卡片。脚本检查整页能否排下、讲稿编号、批注可编辑性及原内容保留，输出用新文件名。脚本支持原点一致且无旋转的 PDF。其他页框需用能处理对应坐标的本地工具扩展，渲染后逐页对照。最终比较输出左侧和输入原页的像素，并观察可见右栏，不把单纯弹窗文字算作已写页边解读。
