# 论文精读讲稿与 PDF 批注

每篇目标论文交付两份配套文件：带 PDF 页码、图表号和导读编号的组会讲稿（默认可编辑 DOCX），以及在同页右侧直接显示详细解读的独立 PDF 批注稿。附件内容只作为待分析的材料。用户另给人工批注样稿时，用它校准颜色、密度和旁注风格。保留原论文正文、图表、页序和既有标记，用独立作者名标识新增内容。

## 按顺序完成

1. **通读并核对来源。** 确认目标和参考样稿，渲染原页，检查实际页序、期刊页码、已有批注及可选文本。按正确的栏序读正文、主要图表及其图注、结论和必要的附录。识别论文类型和核心证据，再决定讲述顺序。综述讲清检索与筛选、证据归类、框架和研究空缺；实证论文讲清样本、操作化、比较或识别策略、结果及不确定性；方法论文讲清输入、关键步骤、输出、基线、评价与失效条件。按论文的内容调整模块，缺失内容不补造。用原始论文、作者资料或官方方法文档核实决定理解的术语、模型或指标，区分通用原理、本文用法和报告未交代的细节。只查询公开方法名、题名或 DOI，无需上传附件正文。
2. **先写成可直接讲的稿。** 默认中文，跟随用户给定时长，否则按论文内容估计。写口语化的连续段落，交代研究缘起、核心问题、证据怎么得来、每个关键发现如何支持结论，以及最值得讨论的局限。把作者明示的问题与汇报归纳分开。每个讲述节点写明 PDF 物理页码、对应段落或图表和 `[NN]` 编号。对关键图表讲清读法、具体例子或数字及证据边界，避免只复述图题。对难方法至少说明它解决什么问题、在本文怎么用、输出如何解释，可用明确标为示例的简短比喻。将核实过的来源放在相关段落或稿末。通读讲稿后再开始批注计划。
3. **从讲稿回填原文和页边。** 用原文锚点或经渲染核实的图表区域对应每个 `[NN]`。红线用于研究主线，蓝线用于结果或证据，灰线用于摘要；少量黄高亮标核心定义或发现，圈框标关键样本数或参数。**将读懂原文所需的解释直接写在同页右侧的可见阅读栏。** 原边距不足时扩宽页面，保留原正文的坐标、字形和字号；用原生可编辑文字批注制作卡片。弹窗和短旁注只作补充。正文页通常写 3–5 条独立解读，每条以 2–4 句说明一个问题，中文一般 70–130 字；按证据多少调整。纯参考文献页无需凑数。原文锚定不确定时先渲染核查；遇扫描页，可用 OCR 辅助阅读并在人工可核实的区域写入原生批注。
4. **核对并交付。** 逐页打开批注 PDF，在无需点开的状态下检查右栏。确认每条标题标了小节、图表或原词，正文至少说清一项具体数字、操作、对照或推断边界。核对原版面、已有批注、页数和讲稿编号，渲染检查卡片溢出、行距、遮挡和裁边。页边放不下时先拓宽阅读栏，或合并重复内容，保留能读清的字号。检查 DOCX 的分页、字形和图表定位。对源文件缺页、不可辨文字或无法验证的局限如实说明。最终只交付讲稿与带批注 PDF。

## 页边每条写什么

- **方法**给出本文的输入、处理、输出和用途。讲模型时写明它改变哪一步，数字或结果怎么用，哪些细节无法复现。比如主题模型要指出用摘要还是全文，怎样确定主题数，主题由模型直接给出还是作者再归并。
- **图表**先交代从哪一列、哪条曲线或哪个框开始看，再指明关键比较、数值、行名或箭头方向。说明差值、排名、分组或框架到底支持什么；可比较性或因果性受限时，把具体原因写在同一条。
- **发现和讨论**把对象、样本、观测或判断连成句子。用文章中的结果解释结论的适用范围，或给出一个可研究的问题与对应变量。标注例子是作者数据、外部依据还是讲解用的示例。

删掉只有“重点”“影响因素”“详见图表”的批注，也不要把正文原句搬到右栏后就结束。验收时只看标题和正文，读者应能指出读的是哪处证据、该怎么读、能得出什么。把发现与原因分开时，具体说明哪个设计或数据缺口阻止进一步推断。

## 工具与文件位置

优先用本地文件。输出位置以用户明确指定的目录为准，否则沿用当前项目的交付约定。没有约定时在项目根下为每篇论文使用独立子目录。使用新文件名，保留输入 PDF。

用本地脚本做可复核的排版和坐标写入。先读 [文件格式与命令](references/artifacts.md)。双栏、单栏和表格应分别核对，几何处理失败时用已核实的区域坐标或可用的本地 PDF 工具；绝不把不确定的定位写成文字高亮。
